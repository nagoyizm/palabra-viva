# Palabra Viva - App de Versículos Diarios

Una aplicación web moderna e inspiradora que te entrega una palabra de aliento diaria, potenciada por Inteligencia Artificial.

## Características

- **Versículo del Día**: Selección automática diaria de pasajes inspiradores.
- **Potenciado por IA**: Utilizamos tecnología avanzada (Groq) para obtener la versión exacta (Reina-Valera 1960) y generar reflexiones profundas.
- **Narración de Voz**: Escucha la palabra de Dios con voz natural.
- **Diseño Premium**: Interfaz limpia, estética religiosa moderna y responsiva.

## Requisitos

Para usar la aplicación, solo necesitas una **Groq API Key** (es gratuita y muy rápida).

1.  Ve a [console.groq.com](https://console.groq.com/keys).
2.  Crea una cuenta y genera una nueva API Key.
3.  Ingrésala en la aplicación al iniciar.

## Instalación y Uso

1.  Clona o descarga este repositorio.
2.  Instala las dependencias:
    ```bash
    npm install
    ```
3.  Inicia el servidor local:
    ```bash
    npm run dev
    ```
4.  Abre tu navegador en el enlace proporcionado (usualmente http://localhost:5173).
